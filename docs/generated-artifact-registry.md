# Generated Artifact Registry

This registry separates source-owned files from generated-owned files.

The goal is simple: reviewers should know what is canonical, what is derived,
and what is safe to regenerate.

## Source-owned

These files or surfaces are the reviewed inputs:

- `.agentsgen.json`
- marker-managed source docs such as `AGENTS.md` and `RUNBOOK.md`
- repo-owned README snippets and explicit marker ranges
- repo commands, architecture notes, policies, and proof inputs

## Generated-owned

These files are projections and should remain reproducible:

- `agents.entrypoints.json`
- `docs/ai/how-to-run.md`
- `docs/ai/how-to-test.md`
- `docs/ai/architecture.md`
- `docs/ai/data-contracts.md`
- `docs/ai/id-context.json`
- `README_SNIPPETS.generated.md`
- proof-loop files under `docs/ai/tasks/<task-id>/` when generated by
  `agentsgen task ...`
- `docs/ai/okf/*` when exported from the existing pack surface

## Public but not runtime

These are public discovery or docs surfaces, not execution authority:

- site pages under `docs/`
- `llms.txt`
- `.well-known/integrations.json`
- `.well-known/agent-card.json`

## Local runtime but not public

These surfaces are local execution helpers, not hosted/public product claims:

- `agentsgen mcp`
- local generated status/readiness outputs
- machine-specific transient artifacts

## Commit rule

Commit generated artifacts only when they are:

- part of the maintained repo contract;
- consumed by CI, tooling, or discovery;
- expected to drift-check in pull requests.

Do not commit disposable local artifacts or cache-like outputs.
