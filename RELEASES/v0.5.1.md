# agentsgen 0.5.1 — leaner context, clearer integrations

## What changed

- The generated Python `AGENTS.md` fixture shrank from 269 lines / 7,709 bytes
  to 133 lines / 4,080 bytes while retaining the verified test command and core
  security guardrails.
- OKF exports now use portable relative links and no longer expose the author's
  absolute local path.
- The ID handoff declares `profiles/<owner>/soul.md` as the primary human
  bootstrap and tells consumers to load deeper profile files only when needed.
- Documentation now defines tested boundaries for agentsgen 0.5.1, SET 0.4.0,
  ID 0.5.2, ABVX Agent Skills 0.15.0, and downstream Git Tweet release publishing.
- CI covers Python 3.11 through 3.14. Tagged releases attach the checked wheel and
  source archive before trusted PyPI publication.
- The optional MCP server supports both the v1 `FastMCP` import and the current
  v2 `MCPServer` API.

## Upgrade

Run `uv tool upgrade agentsgen` or `pipx upgrade agentsgen`, then:

```sh
agentsgen update . --dry-run --print-diff
agentsgen update .
agentsgen check . --all --ci
```

Generated sections become shorter, so review the diff before committing. Text
outside `AGENTSGEN` markers remains untouched.

## Boundaries

The checker validates references but does not execute project commands or prove
that a particular AI client loads generated files. Git Tweet is an independent
downstream consumer of a published GitHub Release.
