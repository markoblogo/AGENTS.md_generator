# agentsgen 0.5.0 — checks you can act on

- Detect missing npm/pnpm/yarn scripts, literal Make targets, and configured paths without executing commands. Unsupported forms are explicitly unverified.
- Detect generated-section drift as well as structural marker problems. Preserve handwritten text during updates.
- Make the basic init/check quickstart work without a README; skip optional aggregate snippets when no README exists.
- Publish three reproducible CLI demos, shorten onboarding, and document the optional SET 0.3.0 integration.
- Run source checks and installed-wheel demos before PyPI publication; isolate missing-key tests from the caller's environment.
- Include the previously unreleased Rabbithole seed export and reversible-work guidance.

Upgrade: `pipx upgrade agentsgen`. Review `.agentsgen.json` if stricter checks find stale references, then run `agentsgen update .` and `agentsgen check . --ci`. These checks do not prove commands execute successfully or that an AI client loads the files automatically.

Companion: SET 0.3.0 pins agentsgen v0.5.0 and adds repo-local planning configuration. Each package remains usable independently.
